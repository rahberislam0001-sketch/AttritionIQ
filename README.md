# AttritionIQ - Employee Attrition Analysis & Prediction

## Run (2 steps)
1. Open terminal / Anaconda Prompt in this folder
2. pip install -r requirements.txt   (skip if you already have Anaconda)
   python app.py
Then open http://127.0.0.1:5000

Pages: Dashboard | Deep Dive | Risk Predictor | Model Performance | Employee Explorer
Works fully offline (Chart.js is bundled, dataset is in data/hr.csv).
